## Назначение и предметная область

Система решает линейную задачу статики для плоских стержневых конструкций, составленных из прямолинейных стержней, соединённых последовательно вдоль общей оси:
- Граничные условия: жёсткие заделки в сечениях, запрещающие продольные перемещения ($\Delta = 0$).
- Внешние нагрузки:
  - Сосредоточенные статические продольные силы $F_j$ в глобальных узлах.
  - Постоянные статические погонные нагрузки $q_i$ вдоль оси каждого стержня.

### Модуль препроцессора 

- Ввод массивов данных:
  - Параметры стержней: длина $L_i$, площадь сечения $A_i$, модуль упругости Юнга $E_i$, предел допускаемых напряжений $[\sigma]_i$.
  - Узлы конструкции: глобальные координаты $X_j$, признак наличия опор (жёстких кинематических связей).
  - Внешние воздействия: сосредоточенные силы $F_j$ в узлах и распределённые нагрузки $q_i$ по длине стержней.
- Интерактивный графический холст (CAD Canvas):
  - Отрисовка масштабируемых стержней с толщиной, пропорциональной площади $A$.
  - Реалистичная визуализация опор/заделок и векторов сил ($F$ и $q$).
  - Динамическая привязка, интерактивный выбор и подсветка элементов по клику.
  - Двусторонняя синхронизация: изменение координат узлов обновляет длины стержней.
- Модуль формальной диагностики:
  - Контроль корректности данных: $L_i > 0$, $A_i > 0$, $E_i > 0$, $[\sigma]_i > 0$.
  - Проверка кинематической неизменяемости (наличие хотя бы одной опоры).
  - Проверка связности цепочки стержней (отсутствие разрывов схемы).
  - Подсветка ошибок ввода в интерфейсе в реальном времени.
- Управление файлами проекта:
  - Экспорт/импорт проекта в родном формате JSON.
  - Экспорт в топологический формат МКЭ (`xr`, `xs`, `xc`, `nb`, `qr`, `qs`) и формат стержней.
  - Экспорт в CSV и структурированные текстовые таблицы.
  - Автосохранение состояния в `localStorage`.

## Стек технологий

- Ядро интерфейса: React 19, TypeScript
- Сборщик: Vite 8 (Hot Module Replacement)
- Стилизация: Tailwind CSS v4, Lucide Icons, Motion
- Desktop Runtime: Electron 45 (независимый исполняемый `.exe` файл для Windows и приложение для macOS)

## Запуск и сборка

### Требования
- Установленный [Node.js](https://nodejs.org/) (версия 18+)

### Установка зависимостей
```bash
git clone https://github.com/howuraa/Jiku.git
cd Jiku
npm install
```

### Веб-версия (режим разработки)
```bash
npm run dev
```
Откройте в браузере: `http://localhost:3000`

### Десктоп-версия (Electron)
```bash
npm run desktop
```

### Сборка исполняемого файла
```bash
npm run build
```
